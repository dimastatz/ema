# Performance Review

Generates evidence-based performance reviews by aggregating 6 months of GitHub and Jira activity data.

## Workflow

1. Collects commits, PRs, and code review activity
2. Aggregates Jira ticket completion and quality metrics
3. Identifies key accomplishments and growth areas
4. Compiles supporting evidence
5. Outputs structured performance review

## Usage

Provide team member name and review period (typically 6 months). Optionally include role context and expectations.
