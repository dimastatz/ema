# Team Health Report

Generates comprehensive team health assessments across four dimensions: delivery, quality, load, and morale.

## Workflow

1. Collects delivery metrics from Jira (velocity, burndown)
2. Analyzes code quality from GitHub
3. Measures team load and capacity
4. Assesses team morale indicators
5. Outputs health report with recommendations

## Usage

Specify time period (weekly, bi-weekly, monthly). Include team size and baseline metrics if available.
