# Incident Postmortem

Generates blameless root cause analyses and structured postmortem reports for incidents.

## Workflow

1. Collects incident timeline and events
2. Identifies contributing factors
3. Determines root causes
4. Compiles structured timeline
5. Outputs complete postmortem report

## Usage

Provide incident identifier or details. Include incident start/end time and affected systems.
