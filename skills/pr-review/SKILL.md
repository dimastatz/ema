# PR Review

Provides structured code review feedback by applying team review checklists to GitHub pull request diffs.

## Workflow

1. Fetches PR diff and metadata
2. Applies team review checklist
3. Identifies potential issues
4. Generates constructive feedback
5. Outputs structured review

## Usage

Provide GitHub PR URL. Include team standards to apply or use defaults.
