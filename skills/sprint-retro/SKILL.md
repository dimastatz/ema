# Sprint Retrospective

Generates sprint retrospectives by pulling sprint data from Jira, analyzing workflow, and surfacing blockers and action items.

## Workflow

1. Pulls sprint data and velocity metrics
2. Identifies completed/incomplete work
3. Surfaces blockers and issues
4. Generates action items
5. Outputs retro report

## Usage

Specify sprint ID or current sprint. Optionally include team size and project context.
